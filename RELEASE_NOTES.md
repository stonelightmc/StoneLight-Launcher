# StoneLight Launcher 1.1.0

## Release

This release keeps the launcher functionality of 1.0.5 and prepares the
official Windows package for Certum Authenticode signing.

## Changed

- Updated the launcher version and active runtime version strings to 1.1.0.
- Added Windows executable metadata for File version and Product version 1.1.0.
- Synchronized the release archive name with `launcher_version` from `config.json`.
- Added a signing and verification script for the Windows release executable.

## Included

- All fixes and features from StoneLight Launcher 1.0.5.
