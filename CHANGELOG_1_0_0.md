# Changelog 1.0.0

## Added

- Full custom-content update workflow for user instances.
- Source discovery for manually added files.
- Selective migration via active content checkboxes.
- Atomic migration flow for Minecraft version/loader changes.
- UX polish for Content Update modal.

## Fixed

- Stuck global status after content update operations.
- Raw service/status messages inside the Content Update modal.
- Loader-version target picker behavior.
- Content Update modal horizontal overflow.

## Changed

- Launcher version bumped to 1.0.0.
- Temporary Stage documentation removed from release package.
