# StoneLight Launcher v1.0.5

Maintained by Ihor Bozhko.
GitHub profile: https://github.com/stonelightmc

StoneLight Launcher is a free open-source, unofficial Minecraft launcher for the StoneLight
community and user-created Minecraft instances. It supports custom instances, account management,
portable Java, Modrinth and CurseForge browsing, and direct installation of mods, resource packs,
shader packs, and modpacks.

## Features

- Microsoft licensed account login with local OAuth callback.
- Offline accounts are available after at least one licensed account exists locally.
- Official StoneLight instance with a separate update flow.
- Custom MultiMC-like instances.
- Vanilla / Fabric / Forge / Quilt / NeoForge support.
- Portable Java manager with automatic version presets.
- Global launch settings: RAM, Java, window mode and graphics options.
- Instance window with folders, mods, resource packs, shader packs, screenshots, logs and settings.
- Modrinth and CurseForge integration:
  - project search;
  - filters by Minecraft version, loader and categories;
  - mods, resource packs, shaders and modpacks;
  - direct installation into the selected instance;
  - modpack update checks;
  - conservative cleanup of obsolete modpack files.
- Official launcher updates through GitHub Releases.
- Soft automatic update check, no more than once per day.
- Legacy Forge compatibility fixes for older Minecraft versions.
- Languages:
  - English;
  - Ukrainian;
  - Kazakh.
